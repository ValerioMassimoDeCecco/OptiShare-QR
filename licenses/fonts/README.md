# Bundled fonts

The font files in `app/src/main/res/font/` contain copyright and license URL
metadata identifying the following upstream projects and the SIL Open Font
License 1.1. Their upstream license texts are reproduced in this directory:

| File | Project | License text |
| --- | --- | --- |
| `jetbrains_mono.ttf` | [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) | [jetbrains-mono-OFL.txt](jetbrains-mono-OFL.txt) |
| `plus_jakarta_sans.ttf` | [Plus Jakarta Sans](https://github.com/tokotype/PlusJakartaSans) | [plus-jakarta-sans-OFL.txt](plus-jakarta-sans-OFL.txt) |
| `space_grotesk.ttf` | [Space Grotesk](https://github.com/floriankarsten/space-grotesk) | [space-grotesk-OFL.txt](space-grotesk-OFL.txt) |

These fonts are not covered by the project's MIT license. Their precise upstream
versions and any modifications to these font binaries still need verification.
